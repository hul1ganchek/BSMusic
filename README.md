# BSMusic
An Android local audio application.

This repository contains the source code for the BSMusic mobile client, developed and defended as a first-year college project.

## Usage
Clone the repo and build it in Android Studio, or download the `.apk` from Releases.

Permissions: 
- allow internal storage.
